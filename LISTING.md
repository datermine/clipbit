# Promo Text

Know what you copied. A tiny menu bar icon that changes with your clipboard: hover to preview, click to reveal, open, or expand. No history, and nothing leaves your Mac.

# Description

ClipBit is a tiny menu bar app that answers one question: what's on my clipboard right now?

Its icon changes with every copy, so you can tell at a glance whether you've got text, a link, an image, a file, or something else, without pasting to find out. Hover for a preview. Click to do the obvious thing.

WHAT THE ICON TELLS YOU
• Text, link, image, file, or folder, each with its own symbol
• A lock when a password manager marks the clipboard as concealed, so ClipBit never reads it
• A quick pulse whenever the clipboard changes

HOVER TO PREVIEW
• Text: the first and last few words, plus character and line counts
• Links: the site's icon, host, and path
• Images: a thumbnail with dimensions and format
• Files: the Finder icon or a real thumbnail, the file name, and where it lives
• Copied several files? The preview says how many more came along

CLICK TO ACT
• Files reveal in Finder (Option-click to open them instead)
• Links open in your browser or mail app
• Images open in Preview
• Text expands into a scrollable view (Option-click to open it in your text editor)
• Click the thumbnail in the preview and it does the same thing

ALSO
• Right-click to clear the clipboard or copy as plain text, stripping formatting
• Optional thumbnail mode shows a tiny version of a copied image right in the menu bar
• Launch at login, adjustable polling interval and hover delay

PRIVATE BY DESIGN
ClipBit keeps no clipboard history and has no accounts, analytics, or servers. Nothing leaves your Mac except a request for a site's icon while you're previewing a link. The app is sandboxed, and the source code is open on GitHub. Buying it here gets you a signed build with automatic updates, and supports development.
